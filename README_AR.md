# NEXT ME — مشروع Android تأسيسي

## اختياراتك المعتمدة
- العربية والإنجليزية؛ الواجهة الحالية عربية أولية، والترجمة الكاملة لم تنفذ بعد.
- استقلالية DAY ONE كهدف سلوكي مع حدود السلامة والصدق.
- المبادرة حسب الشخصية والسياق، دون سقف يومي ثابت.
- لا أوقات هدوء.
- ذاكرة محلية + Firebase؛ التخزين المحلي موجود، ومزامنة Firestore لم تنفذ بعد.
- تصميم داكن وهادئ.
- نصوص فقط.

## الموجود في هذه الحزمة
- Kotlin + Jetpack Compose.
- واجهة أولية لوضعي ONE DAY وDAY ONE.
- حفظ محلي لسجل المحادثات والأحداث والهوية.
- ربط مبدئي بـ Gemini عبر Firebase AI Logic.
- هيكل WorkManager لفحص المبادرة كل 6 ساعات.

## غير المكتمل
1. قرار المبادرة الحقيقي وتوليد رسالة وإشعار Android.
2. مزامنة Firestore للذاكرة.
3. شاشة مراجعة واعتماد تغييرات الهوية من ONE DAY.
4. استرجاع ذاكرة انتقائي ودلالي.
5. الترجمة الإنجليزية الكاملة.
6. قناة الإشعارات وطلب إذن Android 13+.
7. الاختبارات وبناء APK وتجربة الهاتف.

## الإعداد
- Android Studio حديث، JDK 17، Android SDK 35.
- افتح المشروع في Android Studio.
- أنشئ Firebase project وأضف Android app بالمعرف `com.nextme.app`.
- نزّل google-services.json وضعه في مجلد app.
- فعّل Firebase AI Logic وAnonymous Authentication وCloud Firestore.
- أنشئ Firestore وراجع firestore.rules ثم طبقها.
- نفّذ Gradle Sync ثم Run.

لا تضع مفاتيح سرية في التطبيق. لا توجد خدمة مدفوعة مطلوبة في هذه الملفات، لكن الحصص المجانية تتغير وليست غير محدودة. راجع شروط بيانات Gemini المجانية قبل إرسال معلومات حساسة. WorkManager قد يؤجل العمل ولا يضمن توقيتًا دقيقًا.

## التحقق
تم إنشاء ملفات المصدر وحزمة ZIP فقط. لم ينفذ Gradle build أو تثبيت APK أو اختبار Gemini/Firebase على جهاز فعلي.
